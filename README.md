## 🤖 AI Projects

### 🔬 [StructVerify-Lab](https://github.com/orgs/2026-StructVerify-Lab/repositories) &nbsp;·&nbsp; <sub>Clabi · 2026.04 ~ NOW · 4명 팀</sub>

> 범용 수치 팩트체크 플랫폼 · 도메인에 관계없이 문서 내 수치 주장을 LLM으로 추출하고 KOSIS 통계와 비교 판정

- 초기 파이프라인 전체를 단일 스크립트로 직접 구현 (입력 → Claim Detection → Schema Induction → Verification → Explanation)
- **EAV+parent_path** 계층 구조 기반 도메인 비의존적 스키마 설계 (4테이블)
- 4개 LLM 모듈 프롬프트 엔지니어링 — `claim_detector` / `schema_inductor` / `explainer` / `llm_client`
- **KOSIS 262,783건** 카탈로그 마이그레이션 + 영아/UN/IMF 오매칭 차단 필터링
- GitHub Actions CI/CD + AWS EC2 (nginx + pm2) 배포

`NCP HCX` &nbsp;·&nbsp; `Pydantic` &nbsp;·&nbsp; `PostgreSQL+pgvector` &nbsp;·&nbsp; `Docker` &nbsp;·&nbsp; `AWS EC2`

<br>

### 🧠 [Text2Graph](https://github.com/yeseul-kim01/2026-Text2Graph) &nbsp;·&nbsp; <sub>2026.03~04 · 5명 팀 · Stage 2 단독 담당</sub>

> Document-level Relation Extraction — DocRED 데이터셋 기반 ATLOP+DREEAM 학습  
> 🤗 **모델 공개**: [park990/hihi_model](https://huggingface.co/park990/hihi_model)

- 평가 코드의 **Adaptive Threshold 무시 버그** 발견 및 수정 → **F1 56.64% → 60.71% (+4.07pt)**
- ATLOP Loss 구현 오류 수정 (BCE+concat → 논문 원본 Ranking Loss)
- dev 998개 문서 추론 → 10,494개 triple 생성, NetworkX 기반 KG 시각화
- 관계별 정성 분석 — 명시적 관계 80~90% vs 상식 추론 관계 0~12.5%

`PyTorch` &nbsp;·&nbsp; `BERT-base` &nbsp;·&nbsp; `ATLOP` &nbsp;·&nbsp; `DREEAM` &nbsp;·&nbsp; `NetworkX`
